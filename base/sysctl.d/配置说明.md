# sysctl 配置说明

本目录下的 `.conf` 文件用于调整路由器内核参数，涵盖性能调优与安全控制。

---

## 1. `80-performance.conf`

针对 1-2G 内存的嵌入式路由器性能优化：

- **连接跟踪**：`nf_conntrack_max` 保持内核默认（65536），家用路由器绰绰有余。仅调整各状态超时时间（`SYN_RECV=15s`、`TIME_WAIT=30s`、`UDP=60s`、`ESTABLISHED=3600s`），加速回收空闲连接。
- **TCP/UDP 内存上限**：`tcp_mem` 最高 256MB，`udp_mem` 最高 128MB，防止网络栈挤占过多内存导致 OOM。
- **缓冲区**：`rmem/wmem` 最大 16MB，配合 BBR 满足千兆/2.5G 吞吐。`tcp_rmem`/`tcp_wmem` 开启自调节。
- **队列**：提升 `somaxconn=4096`、`netdev_max_backlog=8192`、`netdev_budget=600`，适应突发流量。
- **TCP 优化**：`tcp_syncookies=1`（SYN flood 防护）、`tcp_tw_reuse=1`（TIME_WAIT 复用）、`tcp_fin_timeout=15s`、`ip_local_port_range` 扩大临时端口范围。
- **拥塞控制**：`fq` + `bbr`（需内核 `CONFIG_NET_SCH_FQ` + `CONFIG_TCP_CONG_BBR`）。`-` 前缀保证不支持时静默跳过。
- **多队列 RPS**：`rps_sock_flow_entries=32768`（需内核 `CONFIG_RPS`）。
- **系统缓存**：`swappiness=10`、`vfs_cache_pressure=50`。

---

## 2. `90-router.conf`

路由转发与基础安全设置：

- **IPv4 转发**：`ip_forward=1`。
- **IPv6**：全局关闭（`forwarding=0`、`accept_ra=0`、`accept_source_route=0`），当前无 IPv6 需求。
- **rp_filter 三层设计**：
  - `all.rp_filter=0`：配合 tproxy 打标流量（否则回包被核心丢弃）。
  - `default.rp_filter=2`：新接口默认宽松模式，兼顾基础防护。
  - `wg0.rp_filter=0`、`ts0.rp_filter=0`：VPN/tailscale 接口显式关闭。`-` 前缀保证接口尚未创建时不报错。
  - 注意 sysctl 对 `all` 和 `interface` 取 **MAX**，所以物理口最终值 = `max(0, 2) = 2`，VPN 口 = `max(0, 0) = 0`。
- **ARP 缓存**：提升阈值至 `512/2048/4096`，`gc_stale_time=120s`，适配多 VPN 环境。
- **ICMP 安全**：禁止 redirect（`accept_redirects=0`、`send_redirects=0`）、源路由（`accept_source_route=0`）、广播 ICMP 忽略、异常响应过滤。
- **日志**：`log_martians=0`，不记录火星包（避免日志洪泛）。

---

## 3. 调整建议

- 修改缓冲区或内存配置时，同步检查 `tcp_mem`/`udp_mem` 上限是否匹配实际物理内存。
- 开启 IPv6 时需按接口粒度放开 `forwarding` 和 `accept_ra`，而不是直接改 `all`。
- 启用 `rp_filter` 前需确认是否使用 TProxy/VPN 路由，以免回包被丢弃。
- 修改后应用：`sysctl -p /etc/sysctl.d/*.conf`。
